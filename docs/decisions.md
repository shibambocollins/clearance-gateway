| D-019 | 2026-10-28 | Canonicaliser builds two views, each with a per-unit map back to the original: (1) NFKC per code point with zero-width characters removed; (2) the same with separator runs (whitespace incl. line breaks, `- . / ( )`, Unicode dashes; at most 3 characters) removed **between digits**.
